# Contributing to Cost Tracker

Thank you for your interest in improving **Cost Tracker**!

Cost Tracker is an open-source real-time token cost and prompt cache analytics mod for Command Code.

---

## 1. How to Contribute

### Reporting Issues & Missing Models
- If a new model is missing from the pricing table, or if pricing rates change, please open an Issue with the official provider pricing documentation URL.

### Pull Requests
1. Fork the repository on GitHub.
2. Create your feature branch: `git checkout -b feat/my-improvement`.
3. Adhere to code quality:
  - TypeScript strict typing.
  - Decoupled modules (< 500 lines per module).
  - Flexoki dark palette compliance in UI strings.
4. Run tests locally (`bun test`).
5. Open a Pull Request against `main`.
